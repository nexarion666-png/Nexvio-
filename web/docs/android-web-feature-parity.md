## Verified implementation constraints

- TMDB is used for metadata/artwork only. No general stream provider is configured by the web app.
- Android uses Media3 and can attach HTTP headers; browser media elements cannot arbitrarily reproduce all custom-header behavior.
- M3U import and channel metadata can be handled in browser code, but URL fetches and streams remain subject to CORS, codec, DRM, and provider rules.
- Cloud watchlist/settings helpers target the established `nexvio_profiles` and `nexvio_profile_state` schema and preserve unknown keys when merging state.
- The supplied zip does not include `.git` metadata, so the local snapshot's branch, starting commit, working tree, and existing remote PR state cannot be verified from the archive.
